Chapter 5

Operators & Control Flow

Arithmetic, comparison, bitwise and boolean operators — plus if, while, and for statements that structure your program's logic.

Mojo's operator syntax mirrors Python. Symbols, precedence, and associativity follow Python conventions, so most behavior feels familiar from Python, C, or Rust. A few details are specific to Mojo:

  • Boolean operators are words — and, or, not — never symbols like && or ||.
  • The ternary expression places the condition in the middle: a if cond else b.
  • The caret (^) serves double duty as bitwise XOR and the transfer sigil for ownership.

Precedence within bitwise ops

From highest to lowest: unary ~, then shifts (<<, >>), then &, then ^, then |. Parenthesize when mixing groups.

⚠️ Watch Out:

x^+1 looks like exponentiation to C eyes, but it parses as x ^ (+1) — an XOR! Exponentiation is **. Use spaces around ^ to keep intent clear.

4. Boolean Logic

Logical operators are the keywords and, or, not:

Truthiness

Conditions don't require an explicit == True. Any type implementing the Boolable trait converts to Bool in a condition. Falsy values:

  • False itself, and the integer/float value zero
  • An empty String ("")
  • Empty collections: List, Dict, Set
  • An Optional holding None

Everything else is truthy.

Lexicographic ordering

Comparison operators order strings lexicographically by Unicode scalar values — uppercase letters sort before lowercase:

print("Zebra" < "ant")   # True — 'Z' (90) < 'a' (97)

The for/else clause

The else block runs after the loop completes all iterations — including when the collection is empty. It is skipped only if the loop exits via break (or a return). Classic use: search loops.

def main():
    var age = 20
    var ticket = "adult" if age >= 18 else "child"
    print(ticket)
    # Usable anywhere an expression fits:
    print("even" if age % 2 == 0 else "odd")
