Drill 18 · Future Value & Annuities

Implement compound interest, future value, present value and annuities in Mojo — from the Finance book.

Your task

Port `future_value(pv, rate, years)` to typed Mojo: `def future_value(pv: Float64, rate: Float64, years: Int) -> Float64`. Confirm FVIF at 7% over 10 years is ≈ 1.9672 and that `future_value(1000.0, 7.0, 10)` yields ≈ $1,967.15. Then implement present value discounting (`PV = FV / (1 + r)^n`) and check that needing $50,000 in 10 years at 7% implies ~$25,415 today. Finally compute the future value of an ordinary annuity (`PMT × FVIFA`) and show how an annuity due adds the `(1 + r)` boost.

Based on Future Value & Annuities. Ground your math with Types & Values and Functions. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

Money needed in 10 years at 7% is about $25,415 today. What does that number represent?

Why: PV = FV / (1 + r)^n discounts the future $50,000 back to today: 50,000 / 1.07^10 ≈ $25,415.
Solution

Reference Mojo for FV, PV, FVIFA and annuity-due boost.

def future_value(pv: Float64, rate: Float64, years: Int) -> Float64:
    return pv * (1.0 + rate / 100.0) ** years

def present_value(fv: Float64, rate: Float64, years: Int) -> Float64:
    return fv / (1.0 + rate / 100.0) ** years

def fvifa(rate: Float64, n: Int) -> Float64:
    if rate == 0.0:
        return Float64(n)
    var r = rate / 100.0
    return ((1.0 + r) ** n - 1.0) / r

def fv_annuity(pmt: Float64, rate: Float64, n: Int, due: Bool = False) -> Float64:
    var f = pmt * fvifa(rate, n)
    if due:
        f = f * (1.0 + rate / 100.0)      # annuity-due boost
    return f

def main():
    print(future_value(1000.0, 7.0, 10))  # ≈ 1967.15
    print(present_value(50000.0, 7.0, 10))# ≈ 25415.0
    print(fv_annuity(1000.0, 7.0, 10))    # ordinary annuity
    print(fv_annuity(1000.0, 7.0, 10, due=True))  # due version
