Drill 23 · Linear Programming

Model a product-mix LP, enumerate corner points and verify the optimum — the cornerstone of OR.

Your task

From the textbook's product-mix example, model `max z = 40x₁ + 30x₂` subject to `x₁ + x₂ ≤ 100`, `2x₁ + x₂ ≤ 160`, `x₁ ≤ 60`, `x ≥ 0`. Enumerate the feasible corner points in Mojo (a struct for each point plus a feasibility check) and find the optimum. Verify against the book: `x₁ = 60, x₂ = 40, z = 3600`. Then write the dual program and read the shadow prices (y₁* = 20, y₂* = 10, y₃* = 0), explaining strong duality `z* = w* = 3600`.

Based on Operations Research — A Concise Textbook; work the pivots by hand in The Simplex Method — a working paper. Ground your code with Structs & Traits, Functions and Operators & Control Flow. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

The optimal corner point (60, 40) achieves z = 40·60 + 30·40. What is the optimum?

Why: 40 × 60 + 30 × 40 = 2400 + 1200 = 3600 — the same value the dual achieves, confirming strong duality.
Solution

Reference Mojo enumerating corners, checking feasibility, and reporting the optimum.

@fieldwise_init
struct Corner:
    var x1: Int
    var x2: Int

def feasible(c: Corner) -> Bool:
    return (c.x1 + c.x2 <= 100 and 2 * c.x1 + c.x2 <= 160
            and c.x1 <= 60 and c.x1 >= 0 and c.x2 >= 0)

def objective(c: Corner) -> Int:
    return 40 * c.x1 + 30 * c.x2

def main():
    var best = Corner(0, 0)
    var best_z = 0
    for x1 in range(0, 61):
        for x2 in range(0, 101):
            var c = Corner(x1, x2)
            if feasible(c) and objective(c) > best_z:
                best = c
                best_z = objective(c)
    print(best.x1, best.x2, best_z)   # 60 40 3600

    # Dual:  min 100y1 + 160y2 + 60y3
    #        s.t. y1 + 2y2 + y3 >= 40; y1 + y2 >= 30; yi >= 0
    # Shadow prices y* = (20, 10, 0) -> w* = 3600.
