PRAXIS · CH 01

Drill 03 · Hello Mojo

Get a Mojo program running — both as a script and as a compiled native binary.

Your task

Write `def main(): print("Hello, Mojo!")`. Run it with `mojo hello.mojo`, then compile it with `mojo build hello.mojo` and run the resulting binary. Explain what each command does and why the build step produces a standalone executable.

Based on Chapter 1 · Introduction & Getting Started. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

Which command both compiles the program and produces a named native executable?

Why: `mojo build` compiles to a standalone binary; `-o hello` names the output. The plain / `run` invocations execute via the interpreter instead.
Solution

Reference commands and a short explanation. Starred lines show the key idea.

# hello.mojo
def main():
    print("Hello, Mojo!")

# Run as a script (interpreted):
mojo hello.mojo

# Compile to a native binary:
mojo build hello.mojo -o hello

# Run the compiled binary:
./hello

# Explanation:
# mojo run/plain  -> runs through the interpreter
# mojo build -o   -> AOT-compiles into a standalone executable
#                   (no Mojo needed on the target machine)
