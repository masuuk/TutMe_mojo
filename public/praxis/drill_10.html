PRAXIS · CH 08

Drill 10 · Metaprogramming

Move work from runtime to comptime with parameters, where clauses and comptime control flow.

Your task

Write `def multiplier[factor: Int](x: Int) -> Int` and, in `main`, bind it at comptime: `comptime times_ten = multiplier[10]` then call `times_ten(3)` — expect 30. Add a `where` clause restricting `factor> 0`. Use `comptime if` to choose between two code paths and `reflect[T]` to print the field names of a small struct.

Based on Chapter 8 · Metaprogramming. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

When is a `def multiplier[factor: Int](x: Int) -> Int` instantiated?

Why: Parameters are compile-time values; the compiler generates a specialized function body per distinct parameter value (`multiplier[10]` produces a ×10 function).
Solution

Reference code: parameterized function, `where` clause, comptime if, and reflection.

def multiplier[factor: Int](x: Int) -> Int where factor > 0:
    return x * factor

struct S:
    var a: Int
    var b: String

def show_fields():
    comptime field_count = reflect[S].field_count()
    comptime field_names = reflect[S].field_names()
    comptime for i in range(field_count):
        print(field_names[i])       # a, b

def main():
    comptime times_ten = multiplier[10]
    print(times_ten(3))            # 30

    # comptime-if picks a branch during compilation
    comptime if 4 > 2:
        print("branch A is compiled")
    else:
        print("branch B is compiled")

    show_fields()                   # a, b
