Drill 26 · AI Agent Tool Calling

Turn a chatbot into an agent — describe a tool, let the model request it, execute locally, feed the result back.

Your task

Port the guide's Section 05 pattern to Mojo: the model can't answer "How does Mojo call Python libraries?" from memory, so register a mock search_docs(query: String) -> String tool (swap the body for a vector search in production). Describe it with a JSON schema under tools, let the model decide with tool_choice="auto", inspect message.tool_calls, execute the function locally, and feed the result back as a role: "tool" message carrying the matching tool_call_id. Make a second call so the model composes the final answer from the real data, and confirm the printout references std.python — proof the tool result reached the final generation.

Based on Building AI Agents · Python vs Mojo (Section 05 · Tool Calling). Ground your code with Python & C Interop and Operators & Control Flow. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

When the model decides a question needs a tool, it returns a request instead of text. What must your code do to give it the real result?

Why: Tool results are carried by a role: "tool" message tied to tool_call_id — the assistant-role request and the tool-role result must share that id so the model can pair them.
Solution

Reference Mojo for a tool-calling agent loop over the interop layer.

from std.python import Python

# A mock retrieval tool - swap the body for a vector search in production
def search_docs(query: String) -> String:
    return ("Top hit for '" + query + "': Mojo reaches the Python "
            "ecosystem through std.python interop.")

def main() raises:
    var openai = Python.import_module("openai")
    var json = Python.import_module("json")
    var client = openai.OpenAI()

    # 1) Describe the tool so the model knows it exists and how to call it
    var tools = Python.list(
        Python.dict(
            type="function",
            function=Python.dict(
                name="search_docs",
                description="Search the Mojo documentation",
                parameters=Python.dict(
                    type="object",
                    properties=Python.dict(
                        query=Python.dict(type="string", description="Search term")
                    ),
                    required=Python.list("query"),
                ),
            ),
        )
    )

    var messages = Python.list(
        Python.dict(
            role="user",
            content="How does Mojo call Python libraries?",
        )
    )

    # 2) Ask, letting the model decide when to use the tool ("auto")
    var response = client.chat.completions.create(
        model="gpt-5-mini",
        messages=messages,
        tools=tools,
        tool_choice="auto",
    )

    var message = response.choices[0].message

    if message.tool_calls:
        # 3) The model requested a call - execute it locally
        for var call in message.tool_calls:
            var args = json.loads(call.function.arguments)
            var result = search_docs(String(py=args["query"]))

            # 4) Feed the result back as a "tool" message
            messages.append(
                Python.dict(
                    role="tool",
                    tool_call_id=call.id,
                    content=result,
                )
            )

        # 5) Ask again: the model composes the final answer with real data
        var final = client.chat.completions.create(
            model="gpt-5-mini",
            messages=messages,
            tools=tools,
        )
        print(String(py=final.choices[0].message.content))
    else:
        print(String(py=message.content))
