Drill 27 · Chat Loop, Streaming & Memory

Build a stateful chat agent that streams tokens and trims history — keep cost flat as the conversation grows.

Your task

Every turn re-sends the whole messages history, so cost grows linearly with length (guide Sections 02 & 06). Build a Mojo chat loop that streams output token-by-token with stream=True (Section 04) and applies a sliding window with a budget of six turns: keep the system prompt, then pop(0) the oldest turns once len(messages) > 6. Read lines with input(), break on "exit"/"quit", rebuild the reply from the streamed deltas, append it back as the assistant turn, and trim again after both appends. Confirm every API call carries at most the budget of messages.

Based on Building AI Agents · Python vs Mojo (Sections 02, 04 & 06). Ground your code with Python & C Interop and Operators & Control Flow. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

A sliding-window memory strategy caps cost by doing what?

Why: A sliding window fixes the system prompt and forgets the oldest turns once the budget is exceeded — summarization (option c) is a different, costlier strategy the guide covers separately.
Solution

Reference Mojo for a streaming chat loop with a sliding-window trim.

from std.python import Python, PythonObject

# Sliding window: keep the system prompt, drop the oldest turns
def trim(history: PythonObject, max_history: Int) raises:
    while len(history) > max_history:
        history.pop(0)

def main() raises:
    var openai = Python.import_module("openai")
    var client = openai.OpenAI()
    var max_history: Int = 6

    var messages = Python.list(
        Python.dict(role="system", content="You are a concise coding mentor.")
    )

    while True:
        var user_input = input("You: ")
        var cleaned = user_input.strip().lower()
        if cleaned == "exit" or cleaned == "quit":
            break

        messages.append(Python.dict(role="user", content=user_input))
        trim(messages, max_history)

        # Stream tokens as they are generated instead of waiting for the end
        var stream = client.chat.completions.create(
            model="gpt-5-mini",
            messages=messages,
            stream=True,
        )

        var reply = ""
        for chunk in stream:
            var delta = chunk.choices[0].delta.content
            if delta:
                print(String(py=delta), end="")
                reply += String(py=delta)
        print()

        messages.append(Python.dict(role="assistant", content=reply))
        trim(messages, max_history)
