PRAXIS · CH 09

Drill 11 · Mojo vs Python

Port everyday Python to Mojo 1.x and translate your muscle memory.

Your task

Take the classic Python quadratic solver — `x = (-b ± √(b²-4ac)) / 2a` returning a tuple — and rewrite it in Mojo with typed parameters and a `raises` guard for the negative discriminant. Then translate a Python `@dataclass` into a Mojo struct with `@fieldwise_init`. Finally port a Python `for` loop that sums squares into Mojo, declaring variables with `var`.

Based on Chapter 9 · Mojo vs Python: A Side-by-Side Syntax Tour. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

In Mojo, is it required to annotate the type of every function parameter?

Why: To compile 1.0 code, function parameters require explicit types, and every local is declared with `var` (initialized before first use).
Solution

Reference ports of the quadratic solver, a dataclass, and a summing loop.

def quad(a: Float64, b: Float64, c: Float64) raises -> (Float64, Float64):
    var disc = b * b - 4.0 * a * c
    if disc < 0:
        raise Error("negative discriminant")
    var r = disc ** 0.5
    return (-b + r) / (2.0 * a), (-b - r) / (2.0 * a)

@fieldwise_init
struct User:
    var id: Int
    var name: String

def main():
    try:
        var (x1, x2) = quad(1.0, -3.0, 2.0)   # x1==2.0, x2==1.0
        print(x1, x2)
    except e:
        print("no real roots:", e)

    var u = User(7, "ada")
    print(u.id, u.name)

    var total = 0
    for i in range(1, 6):
        total = total + i * i
    print(total)                            # 55
