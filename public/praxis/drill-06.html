PRAXIS · CH 04

Drill 06 · Functions

Write functions using parameters vs arguments, out/mut/ref conventions and overloading.

Your task

Implement `incr(a: Int) -> Int` that returns `a + 1`, then overload it as `incr(a: Int, out b: Int)` that writes the result into `b`. Call both from `main`. Then write a `mut`-style function that mutates a passed list in place, and one variadic reader function that accepts `*args` and prints each value.

Based on Chapter 4 · Functions. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

For `def incr(a: Int, out b: Int):`, how is `b` passed, and how is the caller's variable affected?

Why: An `out` argument is output-only — the function assigns it and that value is copied back into the caller's variable.
Solution

Reference code: return-style, `out`, `mut`, and variadic `*args`.

def incr(a: Int) -> Int:
    return a + 1

def incr(a: Int, out b: Int):
    b = a + 1

def push_mut(inout xs: List[Int], v: Int):
    xs.append(v)

def sum_all(*args: Int) -> Int:
    var total = 0
    for x in args:
        total += x
    return total

def main():
    var x = incr(41)          # x == 42
    var y: Int
    incr(10, out y)           # y == 11
    print(x, y)

    var nums = List[Int]()
    push_mut(nums, 7)         # in-place mutation
    print(sum_all(1, 2, 3, 4))# variadic -> 10
