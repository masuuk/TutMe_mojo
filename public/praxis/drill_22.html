Drill 22 · Coordinate Records

Model coordinate records from the geomatics shelf and process a small feature set.

Your task

Model a `Point` struct with `var x: Float64` and `var y: Float64` and a `distance(a: Point, b: Point) -> Float64` function using the Euclidean formula from the geomatics shelf. Then extend it: read a list of points from a `List[Point]`, compute the bounding box, the nearest neighbour of each point, and the per-point distance to a reference point. Print a small tabular report of the results. Consider how you would attach attributes to each point (e.g. an id) using a second struct.

Related geomatics material: GNSS Surveying and The Karney-Krueger Equations. Ground your code with Structs & Traits, Types & Values and Operators & Control Flow. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

The bounding box of a set of points is defined by what?

Why: The bbox is the smallest axis-aligned rectangle containing the set: (minX, minY) to (maxX, maxY).
Solution

Reference Mojo for a Point struct, distance, bbox, and nearest-neighbour printing.

struct Point:
    var x: Float64
    var y: Float64
    fn __init__(inout self, x: Float64, y: Float64):
        self.x = x
        self.y = y

fn distance(a: Point, b: Point) -> Float64:
    return ((a.x - b.x) ** 2 + (a.y - b.y) ** 2) ** 0.5

struct BBox:
    var min_x: Float64
    var min_y: Float64
    var max_x: Float64
    var max_y: Float64

fn bounding_box(pts: List[Point]) -> BBox:
    var b = BBox(pts[0].x, pts[0].y, pts[0].x, pts[0].y)
    for p in pts:
        b.min_x = min(b.min_x, p.x)
        b.min_y = min(b.min_y, p.y)
        b.max_x = max(b.max_x, p.x)
        b.max_y = max(b.max_y, p.y)
    return b

def main():
    var pts = List[Point](Point(0, 0), Point(3, 4), Point(-1, 2))
    var bb = bounding_box(pts)
    print(bb.min_x, bb.min_y, bb.max_x, bb.max_y)   # -1 0 3 4

    var origin = Point(0, 0)
    for p in pts:
        print("dist to (0,0):", distance(p, origin))
