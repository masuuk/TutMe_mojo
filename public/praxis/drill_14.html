Drill 14 · Modules & Toolchain

Structure code into modules and packages and tune the build from the command line.

Your task

Split a small program across two modules (e.g. `math.mojo` with a `square` function and `main.mojo` that imports it). Create a package directory with `__init__.mojo` and re-export a name. Read a compile-time define using `get_defined_bool[]` or `is_defined[]`, and branch on it with `comptime if`. Print the current `CompilationTarget` and its accelerator flags.

Based on Chapter 12 · Modules, Packages & Toolchain. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

What file must exist for a folder to be importable as a package?

Why: In Mojo 1.0, a package directory is marked by a `__init__.mojo` file, which can re-export the public API.
Solution

Reference layout and code for modules, packages, compile-time defines, and the target.

# math.mojo
fn square(x: Int) -> Int:
    return x * x

# main.mojo
import math
from std.env import get_defined_bool, is_defined
from std.os import compilation_config

def main():
    print(math.square(9))               # 81

    # package: dir with __init__.mojo that re-exports a name
    # from mypackage import helper

    # compile-time defined flag
    comptime if is_defined["MY_FLAG"]:
        print("MY_FLAG was defined at build time")
    var has_fast = get_defined_bool["MOJO_ACCELERATOR"]
    print(has_fast)

    var conf = compilation_config
    print(conf.target)                  # e.g. AArch64
    print(conf.accelerator_usage)
