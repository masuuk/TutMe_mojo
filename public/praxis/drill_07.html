Drill 07 · Operators & Control Flow

Drive decisions and loops using Mojo's operators and control structures.

Your task

Write a program that: (1) computes `7 // 2` and `7 / 2` and explains the difference; (2) uses boolean `and` to chain comparisons: `x > 0 and x < 10`; (3) prints a ternary `"even" if n % 2 == 0 else "odd"`; (4) sums the numbers 1..N with a `while` loop; (5) loops over a list with `for`, using `for ref` to double each element in place. Add a `break`/`continue` example.

Based on Chapter 5 · Operators & Control Flow. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

What does `7 // 2` evaluate to in Mojo?

Why: `//` is floor division — the quotient rounds down to the integer 3, losing the fractional 0.5.
Solution

Reference code covering division, comparisons, ternary, loops, and break/continue.

def main():
    print(7 // 2)   # 3   floor division - integer quotient
    print(7 / 2)    # 3.5 true division keeps the fraction

    var x = 5
    print(x > 0 and x < 10)         # True (and chain)
    print("even" if x % 2 == 0 else "odd")  # ternary -> odd

    var total = 0
    var n = 1
    while n <= 100:
        total += n
        n += 1
    print(total)                    # 5050

    var nums = [1, 2, 3, 4]
    for ref v in nums:
        v = v * 2                   # in-place: [2, 4, 6, 8]
    print(nums)

    for i in range(10):
        if i % 2 == 0: continue     # skip evens
        if i > 7: break             # stop at 9
        print(i)
