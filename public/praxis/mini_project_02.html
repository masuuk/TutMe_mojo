PRAXIS · CH 08–15

Mini Project · Metaprogrammed Shape Library

Combine structs, traits, comptime, errors, closures and docstrings into one small package.

Your task

Build a `shapes` package whose modules export parameterized structs (Circle, Rectangle) that conform to a `Shape` trait with `area()` and docstring-complete public methods. Write a comptime-parameterized `scaled[T: Shape]` helper, raise a typed `ShapeError` for invalid sizes, and use a closure for reporting. Structure it as a package with `__init__.mojo`, document everything, and verify with `mojo build`.

Builds on structs & traits, metaprogramming, errors, modules, closures, docstrings. Do the problem before looking for a solution. If you forget syntax, use the Mojo Library.
