Drill 24 · Queuing Theory

Compute M/M/1 steady-state measures and check Little's Law — decision science for waiting lines.

Your task

For an M/M/1 queue with arrival rate λ = 6/hour and service rate μ = 8/hour, write a Mojo program that computes ρ, the queue measures L, Lq, W, Wq (from the textbook's formulas), and the probability the server is idle P₀ = 1 − ρ. Verify against the book's worked example: ρ = 0.75, L = 3, Lq = 2.25, W = 0.5 h, Wq = 0.375 h. Then confirm Little's Law `L = λ·W` holds numerically. Extra: Monte-Carlo estimate of the average wait and compare to Wq.

Based on Operations Research — A Concise Textbook. Ground your code with Operators & Control Flow and Functions. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

For λ = 6/h and μ = 8/h, what is the utilisation factor ρ?

Why: ρ = λ / μ = 6 / 8 = 0.75 — the share of time the server is busy, so P₀ = 1 − 0.75 = 0.25.
Solution

Reference Mojo for the M/M/1 steady-state formulas.

def mm1(lambda_: Float64, mu: Float64):
    var rho = lambda_ / mu            # utilisation
    var l = rho / (1.0 - rho)         # avg in system
    var lq = rho * rho / (1.0 - rho)  # avg in queue
    var w = l / lambda_               # avg time in system
    var wq = lq / lambda_             # avg wait in queue
    var p0 = 1.0 - rho                # server idle probability
    print("rho", rho, "L", l, "Lq", lq)
    print("W", w, "Wq", wq, "P0", p0)
    # Little's law: L = lambda * W  -> 3 = 6 * 0.5  ✓

def main():
    mm1(6.0, 8.0)                     # rho .75 L 3 Lq 2.25 W .5 Wq .375
