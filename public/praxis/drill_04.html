PRAXIS · CH 02

Drill 04 · Copy vs Move

Master variable declarations, scoping, and the difference between copying and transferring values.

Your task

Write a program that creates `var source = String("Hello")`. Copy it into another variable, then move it with `source^` into a third. After the move, print all three — and explain the state of `source`. Add a `comptime` constant and a `ref` binding, and describe how each changes when you reassign the original.

Based on Chapter 2 · Language Basics. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

After `var moved = source^`, how should you describe `source`?

Why: `source^` transfers ownership — the value moves into `moved`, leaving `source` unable to be used again (the compiler enforces this).
Solution

Reference code showing copy, move, comptime const, and a `ref` binding.

def main():
    var source = String("Hello")

    var copied = source       # copy: source still usable
    print(copied)             # Hello

    var moved = source^       # move: source is now dead
    print(moved)              # Hello
    # print(source)           # ERROR - source was moved out

    comptime var n = 42       # comptime constant, evaluated at compile time
    # n = 43                  # ERROR - comptime vars cannot be reassigned

    var m = 10
    ref r = m
    r = 99                    # writes through the reference
    print(m)                  # 99
