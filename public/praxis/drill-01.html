Drill 01 · Temperature Converter

Write a function that converts Celsius to Fahrenheit.

Your task

Implement `F = C × 9/5 + 32`. Test it with 0, 25 and 100 degrees.

Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

Using the formula `F = C × 9/5 + 32`, what is 100 °C in Fahrenheit?

Why: 100 × 9/5 = 180, plus 32 = 212 °F.
Solution

A reference implementation in Mojo — check yours against it after you have written it yourself.

def c_to_f(c: Float64) -> Float64:
    return c * 9.0 / 5.0 + 32.0

def main():
    for c in [0.0, 25.0, 100.0]:
        print(c, "C ->", c_to_f(c), "F")
