PRAXIS · CH 03

Drill 05 · Types & Values

Build values from Mojo's core types: numerics, strings, SIMD vectors and tuples.

Your task

Write a program that: (1) declares an `Int`, a `Float64`, a fixed-width `Int8` and a `Bool` and prints their types; (2) multiplies two `SIMD[DType.int8, 4]` vectors element-wise; (3) builds a `String` and prints `byte_length()` vs `count_codepoints()`; (4) stores a heterogeneous pair in a tuple and unpacks it. Interpolate one of the results into a `t"..."` template string.

Based on Chapter 3 · Types & Values. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

A `SIMD[DType.int8, 4]` value holds how many lanes?

Why: The second type parameter is the number of lanes — `SIMD[element_type, N]`. Here `4` means 4 packed int8 lanes.
Solution

Reference code covering core scalars, SIMD, strings and tuples.

def main():
    var i: Int = 42
    var f: Float64 = 3.14
    var b: Int8 = -7
    var t: Bool = True
    print(i, f, b, t)

    var v1 = SIMD[DType.int8, 4](1, 2, 3, 4)
    var v2 = SIMD[DType.int8, 4](2, 3, 4, 5)
    print(v1 * v2)             # [2, 6, 12, 20]

    var s = String("héllo")
    print(s.byte_length())     # 6  (h,e,',',l,l,o = bytes)
    print(s.count_codepoints())# 5  (é is one codepoint)

    var pair = (100, "maps")
    var (n, name) = pair
    print(n, name)

    var greeting = t"Result: {n} {name}"
    print(greeting)
