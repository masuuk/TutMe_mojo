Drill 16 · Literals & Expressions

Write dense, idiomatic Mojo using t-strings, the walrus operator and comprehensions.

Your task

Build a report with t-strings: interpolate `{name}`, `{1 + 1}`, and show literal braces with `{{ }}`. Use the walrus operator: declare `var n: Int` first, then `if (n := compute()) > 0:`. Produce `var squares = [x * x for x in range(10)]` as a comprehension, then a set comprehension of even squares. Slice a list and print the result. Confirm what type `t"..."` produces and how to convert it.

Based on Chapter 14 · Literals, Expressions & Statements. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

What does the `t` prefix on `t"..."` produce?

Why: `t"..."` is a template string literal: `{expr}` interpolates a value, and `{{` / `}}` print literal braces.
Solution

Reference code for t-strings, the walrus operator, comprehensions and slices.

def compute() -> Int:
    return 5

def main():
    var name = "ada"
    print(t"Hello {name} · 1+1 = {1 + 1} · {{literal}}")

    var n: Int
    if (n := compute()) > 0:
        print("computed", n)          # computed 5

    var squares = [x * x for x in range(10)]
    print(squares)                     # [0,1,4,...,81]

    var evens_set = {x for x in squares if x % 2 == 0}
    print(evens_set)                   # {0,4,16,36,64}

    var sliced = squares[1:4]
    print(sliced)                      # [1,4,9]
