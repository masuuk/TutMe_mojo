PRAXIS · CH 13

Drill 15 · Closures & Lambdas

Capture state explicitly and write single-expression lambdas.

Your task

Write a nested function with a capture list: `var multiplier = 3` in `main`, then `def scale(x: Int) {imm multiplier} -> Int: return x * multiplier` — print `scale(5)` and expect 15. Rebuild it with `{mut}` and confirm the captured value can be reassigned between calls. Then write a one-line lambda for squaring and a thin lambda (no captures) usable as a callback.

Based on Chapter 13 · Closures & Lambda Expressions. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

In a Mojo closure, the capture list `{imm multiplier}` does what?

Why: The closure must list what it captures. `imm` means it holds the value immutably — it can read it but not change it.
Solution

Reference code for immutable and mutable captures, plus lambdas.

def main():
    var multiplier = 3

    def scale(x: Int) {imm multiplier} -> Int:
        return x * multiplier
    print(scale(5))               # 15

    def bump() {mut multiplier} -> Int:
        multiplier += 1           # mut capture can change it
        return multiplier
    print(bump())                 # 4
    print(bump())                 # 5

    var square = lambda a: a * a  # lambda
    print(square(9))              # 81

    def apply_thin(cb: fn() -> Int) -> Int:
        return cb()
    var r = apply_thin(lambda: 42)  # no captures - thin lambda
    print(r)                        # 42
