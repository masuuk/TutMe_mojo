PRAXIS · CH 06

Drill 08 · Structs & Traits

Model a domain value as a struct and make it satisfy a trait contract.

Your task

Define a `struct Point` with `var x: Int` and `var y: Int` via `__init__(out self)`. Give it a `mut` setter, a `@staticmethod` factory `Point.from_origin()`, and conform to `Copyable`. Then define a `trait HasMagnitude` with a required `magnitude(self) -> Float64` method and make a generic function that uses it (`Some[T]`). Build a `Complex` type that overloads `__add__`.

Based on Chapter 6 · Structs & Traits. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

What does declaring `struct Point(Copyable):` mean for copying a `Point`?

Why: Conforming to the `Copyable` trait declares that the type provides a working copy, which the compiler uses to allow value copies.
Solution

Reference code: a copyable struct, a trait with a generic consumer, and operator overloading.

trait HasMagnitude:
    fn magnitude(self) -> Float64

fn report[T: HasMagnitude](v: T) -> Float64:
    return v.magnitude()

struct Point(Copyable, HasMagnitude):
    var x: Int
    var y: Int

    fn __init__(inout self):
        self.x = 0
        self.y = 0

    fn __init__(inout self, x: Int, y: Int):
        self.x = x
        self.y = y

    fn magnitude(self) -> Float64:
        return ((self.x * self.x + self.y * self.y).to_f64()) ** 0.5

    @staticmethod
    fn from_origin() -> Point:
        return Point(0, 0)

struct Complex:
    var re: Float64
    var im: Float64

    fn __add__(self, other: Complex) -> Complex:
        return Complex(self.re + other.re, self.im + other.im)

def main():
    var p = Point(3, 4)
    print(report(p))          # 5.0 via the trait
    var c = Complex(1, 2) + Complex(3, 4)
    print(c.re, c.im)         # 4.0 6.0
