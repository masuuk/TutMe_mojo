Drill 17 · Docstrings

Document public APIs with labeled, compiler-validated docstrings.

Your task

Write a function `def resize[dtype: DType](data: List[Scalar[dtype]], size: Int, fill: Scalar[dtype] = 0) raises -> List[Scalar[dtype]]` from Chapter 15 and give it a complete docstring: a one-line summary, then `Parameters`, `Args`, `Returns` and `Raises` sections. Add a custom label (e.g. `Preconditions:`) and hide one helper with `@doc_hidden`. Explain what the compiler checks and its diagnostic flag.

Based on Chapter 15 · Docstrings. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

What does Mojo's compiler check about a labeled docstring?

Why: Structured labels are validated against the signature the compiler knows — missing or extra labels raise a doc mismatch diagnostic.
Solution

Reference docstring for `resize`, plus a helper hidden with `@doc_hidden`.

@doc_hidden
def _pad[dtype: DType](data: List[Scalar[dtype]], size: Int, fill: Scalar[dtype]) -> List[Scalar[dtype]]:
    var out = List[Scalar[dtype]]()
    for i in range(size):
        out.append(data[i] if i < len(data) else fill)
    return out^

def resize[dtype: DType](data: List[Scalar[dtype]], size: Int, fill: Scalar[dtype] = 0) raises -> List[Scalar[dtype]]:
    """Resize a list of scalar values to a target length.

    Parameters:
        dtype: The element type of the data.

    Args:
        data: Original list to resize.
        size: Desired output length.
        fill: Value used to pad when growing.

    Returns:
        A new list of the given size.

    Raises:
        Error: if `size` is negative.

    Preconditions:
        `size >= 0`.
    """
    return _pad(data, size, fill)^
