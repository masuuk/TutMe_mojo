Drill 13 · Python & C Interop

Call into Python and the C ABI without leaving Mojo.

Your task

Use `from std.python import Python` and `var np = Python.import_module("numpy")`. Build `np.arange(15).reshape(3,5)` and print both the array and `ar.shape`. Pass a Python function a Mojo value and read the result back. Then write an `external_call` to a libc function (e.g. `abs` from `std.ffi`) and print the return value.

Based on Chapter 11 · Python & C Interop. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

Why does Mojo provide the `Python` module at all, alongside its own types?

Why: The CPython-interop bridge lets Mojo call into the Python runtime so you can keep using mature libraries like numpy instead of reimplementing them.
Solution

Reference code for numpy interop plus a libc `external_call`.

from std.python import Python
from std.ffi import external_call, c_int

def main() raises:
    var np = Python.import_module("numpy")
    var ar = np.arange(15).reshape(3, 5)
    print(ar)             # 3x5 array
    print(ar.shape)       # (3, 5)

    # pass a Mojo value into a Python function and read back
    var ox = np.float64(3.7)
    var doubled = np.multiply(ox, 2.0)
    print(doubled)        # 7.4

    # libc abs via the FFI
    var n = c_int(-17)
    var r = external_call["abs", c_int](n)
    print(r)              # 17
